# Discover Albania

A modern, responsive tourism website prototype for Albania — experiences marketplace and AI-style trip planner.

## Features

- Cinematic hero section
- Destinations grid (Riviera, Albanian Alps, Berat, Blue Eye)
- Filterable experiences with ratings and pricing
- Interactive trip planner
- Traveler testimonials
- Fully responsive design
- Clean, modern UI

## Live Demo

Once deployed to GitHub Pages, the site will be available at:
`https://YOUR-USERNAME.github.io/discover-albania/`

## Local Preview

1. Download or clone the repository
2. Open `index.html` in any browser

## Deploy to GitHub Pages

1. Create a new public repository on GitHub (e.g. `discover-albania`)
2. Upload all files from this project (including the `searched_images` folder)
3. Go to **Settings → Pages**
4. Set source to **Deploy from a branch** → `main` → `/ (root)`
5. Your site will be live in a few minutes

## Project Structure

```
index.html          → Main website
styles.css          → Styles
script.js           → Interactivity (filters, planner, menu)
searched_images/    → Photos
README.md           → This file
```

## Notes

This is a high-fidelity static prototype.  
In a production version you would connect the booking buttons and trip planner to a real backend, payment system, and local operators.

Built as a demonstration of an Albania-focused tourism experiences platform.
